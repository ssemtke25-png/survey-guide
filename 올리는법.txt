땅 측량 길잡이 (웹 버전) 올리는 법

1. 파일 4개
   index.html   : 화면과 계산 (고칠 일 거의 없음)
   config.js    : 브이월드 인증키 넣는 곳 (여기만 고치면 됨)
   contacts.js  : 시군구 지적부서 연락처 (경북 22개 시군 틀만 들어 있음, 전화 빈칸)
   올리는법.txt : 이 안내

2. GitHub Pages에 올리기
   kijun 앱과 같은 방법. 새 저장소(예: survey-guide)를 만들고 위 파일을 그대로 올린 뒤
   Settings > Pages 에서 main 브랜치를 켜면 https://아이디.github.io/survey-guide/ 로 열림

3. 브이월드 키
   브이월드 오픈API에서 인증키를 새로 받거나 기존 키에 서비스 URL을 추가
   (서비스 URL = 위 GitHub Pages 주소)
   config.js 의 VWORLD_KEY 에 키, VWORLD_DOMAIN 에 https://아이디.github.io 를 넣음
   키가 없으면 지도는 OpenStreetMap만 나오고, 땅 누르기와 주소 찾기는 안 됨 (계산은 됨)

4. 되는 것
   주소나 지번 검색, 내 위치, 지도에서 땅 누르기
   누르면 지번, 지목, 공시지가(연속지적도 값), 면적(도형으로 잰 값)이 자동으로 채워짐
   지번이 산이면 임야로 자동 바뀜
   필지 PNU 앞 5자리로 시군구를 찾아 contacts.js 에 전화가 있으면 전화 버튼이 나옴

5. 알아 둘 점
   면적은 지도 도형으로 잰 근사값이라 대장 면적과 조금 다를 수 있음 (화면에 고치라고 안내함)
   넓은 땅 가산(기계·재료 경비)은 LX 답변 전까지 시험 계산
   연락처 엑셀을 채워 주면 contacts.js 로 바꿔 드림
